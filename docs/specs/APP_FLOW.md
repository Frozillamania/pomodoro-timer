# Journeys and controls
All actors are local users; no authentication. J1: launch → drag dial → Start → Pause → relaunch → Reset. J2: enable sound/blink → complete a session → paused next phase. J3: close → menu bar Open → drag upper frame → Quit. A1 dial → setTimer → persisted paused duration and visible countdown; retry by dragging. A2 Start/Pause → toggleTimer → persisted deadline/remaining; shows opposite action. A3 Reset → resetTimer → paused focus duration. A4 sound/blink → setters → persisted preference and accessible On/Off state; toggle again to undo. A5 Open/Quit/Close → native window/app lifecycle; no timer reset. A6 pin → window level + persisted preference. A7 save/load failure alert → preserved state file, disabled edits on invalid input; quit and recover file before retry. Checks: core tests, isolated real native input and inspected screenshot. Each action is reachable in the window or menu bar, and a save error keeps the last saved state.
