# POMODORO Timer
A compact, local macOS timer for sharing as a standalone source project. Scope: draggable timer dial, start/pause/reset, focus and break phases, optional completion sound and blink, smoky glass, menu bar entry, app icon. No tasks, accounts, network connections or personal infrastructure. Public publishing and licensing remain the owner's decision. Existing full app is renamed POMODORO without changing its identity or data directory.
