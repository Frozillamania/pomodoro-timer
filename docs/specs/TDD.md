# Architecture and stack decision
Reuse the user's explicit selection: native Swift + SwiftUI/AppKit. Same macOS 14 minimum, Swift package, zero dependencies, JSON state. No material stack change; trade-off: macOS only. An independent target contains only timer, styling and persistence. No dependency on the personal app, Google, Echo, SSH or TRIAGE. Separate bundle identity and Application Support directory prevent sharing personal state. Export only this directory into a fresh Git repository; private parent history is excluded. Revisit only for a requested non-Mac platform. Timer deadlines use wall time; sleeping Macs reconcile once awake. One model owns a one-second ticker; phase transitions pause until the user starts again. Invalid files remain untouched and read-only; saves are atomic, directories 0700/files 0600. Finite bounded durations required before mutations or encoding. No notification permission, account setup or service needed.
